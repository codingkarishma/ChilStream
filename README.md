# 🌊 ChillStream

## 📌 Project Overview

**ChillStream** is a real-time, full-stack language exchange and messaging platform built to help people connect, communicate, and build meaningful cultural connections.

The platform combines **real-time messaging, language-based connections, and video communication** into one interactive experience. Users can discover language partners, exchange messages, make friends, and communicate through 1-on-1 or group video calls.

ChillStream focuses on creating a personalized social experience through **32 unique UI themes**, real-time interactions, secure authentication, and a scalable architecture powered by Stream.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/codingkarishma/ChillStream.git
cd ChillStream
```

### 2. Configure Environment Variables

Create a `.env` file inside the `backend` directory:

```env
PORT=5001
MONGO_URI=your_mongo_uri
STREAM_API_KEY=your_stream_api_key
STREAM_API_SECRET=your_stream_api_secret
JWT_SECRET_KEY=your_jwt_secret
NODE_ENV=development
```

Create a `.env` file inside the `frontend` directory:

```env
VITE_STREAM_API_KEY=your_stream_api_key
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Start the Backend

```bash
npm run dev
```

### 5. Install Frontend Dependencies

Open a separate terminal:

```bash
cd frontend
npm install
```

### 6. Start the Frontend

```bash
npm run dev
```

The frontend will be available at the local development URL provided by Vite.
